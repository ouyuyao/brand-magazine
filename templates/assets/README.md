# assets/ —— 参考图（Stage A 的输入）

⚠️ **这个目录是必填的，不是可选的。** 本引擎的**页数 = 参考图张数**，
每页的 `canvas` 也必须等于该页参考图的真实像素尺寸。没有参考图：

- `node build.js` → 退出码 2：`✗ layout/ 里没有版式 JSON（页数 = 参考图张数）`
- `python tools/refcheck.py` → 退出码 1（H1 不过）
- 你也无从解析骨架——`refscan.py` / `refgrid.py` 都是对着参考图跑的

**出厂示例被隔离在 `ref/_demo/`**（`_` 开头 = 引擎不计入）。
要看得显式跑 `node tools/demo.js --enable`，那是示例不是产出。

---

## ref/ —— 参考版式图

- **用途**：① 解析骨架的输入（`refscan.py` / `refgrid.py`）；
  ② `pageNN.html` 里 `.ref-overlay` 叠图层。打开页面按 **`O`** 键**三态循环**
  （关 → 叠参考图 → 叠差异图），用来核对「复刻像不像」。
- **文件名**：由 `layout/NN.json` 的 `"ref"` 字段指定（如 `"ref": "p01.jpg"` → `assets/ref/p01.jpg`）。
  **第 i 页的参考图就是第 i 页的复刻对象**（骨架级复刻的验收凭据）。
- **张数必须等于页数**（`layout/*.json` 的个数）——`build.js` 与 `refcheck.py` 都会硬拦。
- 用**原始分辨率**的图，**不要用被压缩 / 缩放过的小图**：`canvas` 要照它的真实尺寸写，
  喂一张被缩过的图进去，`canvas` 就错了，后面所有叠图目检都失去意义。
- 生成叠图层的关键代码在 `build.js`：

  ```js
  const ref = L.ref ? `assets/ref/${L.ref}` : '';
  ```

## ref/ 下的自动产物（都是 `_` 开头，引擎不计入，freeze 会剔除）

| 目录 | 谁生成 | 里面是什么 |
|---|---|---|
| `_scan/` | `tools/refscan.py` | 候选带缝 / 带内分栏 / 真实尺寸（`.json`）+ 叠线图 + 投影曲线 |
| `_grid/` | `tools/refgrid.py` | 百分比坐标网 / 叠图 / **差异热图**（`<name>_diff.png` → `O` 第三态用它）/ 局部放大 |
| `_demo/` | 出厂自带 | 示例参考图（`demo.js --enable` 复制到顶层） |
| `_stripped` | `tools/freeze.js --ref-mode strip` | 标记文件：参考图未随 skill 分发，`refcheck` 的 H1/H2/H3 自动降级 |

## ⚠️ 版权与分发

如果你放入的是**第三方刊物扫描件 / 网站采集图**：

1. **仅限内部叠图比对**——`O` 键用。不得复制其中的任何原始文字或图像到成品。
2. **不随成品分发**、不进入对外素材包。交付时 `assets/ref/` 可以整个不带。
3. 必须登记进项目根的 `ASSETS.md`：来源（网址/刊名）、采集日期、
   标注「仅作版式参考，不复制任何原始文字与图像」、分发范围「仅内部比对」。

> 引擎是**骨架级复刻**，不是像素级描摹：分区比例、层级、留白节奏、元素相对位置参考它，
> 但文字**一律重写**、配色**走品牌包**、素材**全用自己的**。
> 这是「借鉴版式语言」与「抄袭版面」的分界线。

## 其他子目录

如果要放索引页缩略图之类的中间产物，自己建目录即可——
`assets/` 下除 `ref/` 外的内容引擎不读取。
`index.html` 的缩略图直接从 `_shots/pageNN.png` 取，不需要额外生成。
